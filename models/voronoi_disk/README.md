# ストレッチポール用連結キャップ (Voronoi End Cap)

半円柱形状のストレッチポール2つをつなげて円柱形状にするためのエンドキャップです。

## 用途・設計背景

* **用途**: 半円柱ストレッチポール2本を両端から固定し、1本の円柱ポールとして連結・使用するためのキャップ。
* **荷重条件**: 基本的に大きな荷重はかかりませんが、使用中に偶発的にキャップ部分へ体が乗ってしまう可能性があるため、ラジアル方向（径方向の押し潰し・圧縮荷重）に耐えられるようスリーブ根元に R 2.0 mm の応力緩和フィレットを設けています。
* **端面構造**: 軽量化と円筒の真円度保持（座屈防止）のため、端面にはボロノイ構造（OpenSCADネイティブ生成）を採用しています。

## 主要寸法

| パラメータ | 寸法 | 説明 |
| :--- | :--- | :--- |
| 内径 (`fit_id`) | 148.0 mm | ポール外径用嵌合部 |
| スリーブ肉厚 (`sleeve_t`) | 2.0 mm | 外径: 152.0 mm |
| 端面板厚 (`plate_t`) | 3.0 mm | 全体高さ: 24.0 mm（スリーブ深さ: 21.0 mm） |
| 立ち上がりフィレット (`fillet_r`) | 2.0 mm | スリーブ内壁根元の応力緩和R |
| ストッパー受座幅 (`stop_rim_w`) | 3.5 mm | ポール端面突き当て部 |

## ビルド方法

外部依存（Python等）なしで、OpenSCAD単体でビルド可能です。

```bash
openscad -o voronoi_disk.stl voronoi_disk.scad
```
