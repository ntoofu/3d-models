# Voronoi Roller End Cap (ボロノイ肉抜き 円柱キャップ / コロ仕様)

円柱（丸パイプ・丸棒）の両端に装着し、コロ（ローラー）として接地面からのラジアル荷重を受ける用途に最適化したエンドキャップモデルです。
外部ツールやPythonへのビルド依存を完全に撤廃し、**純粋な OpenSCAD コード単体（Pure OpenSCAD）でポアソンディスク分布生成からボロノイ分割、均一梁・フィレット成形まで完結**する完全自律型パラメトリックモデルとして構築されています。

## 特徴

- **完全自律型 OpenSCAD 実装 (ビルド依存ゼロ)**:
  - **シード点生成**: OpenSCADの再帰関数による Mitchell's Best-Candidate 法（ポアソンディスクサンプリングの高精度近似）をネイティブ実装。
  - **ボロノイ分割**: 2D 垂直二等分線半平面クリッピング（Half-space bisection difference）により、外部ライブラリ不要でボロノイセルを直接計算。
  - **梁幅・角フィレット**: OpenSCADのネイティブ `offset()` 機能を用い、均一な梁幅（2.2 mm）と角丸め（R 0.8 mm）を瞬時に形成。
  - 全体のSTLコンパイル時間は **約6〜7秒** と極めて高速。
- **円柱受容スリーブ（外径 152.0 mm / 内径 148.0 mm）**:
  - 内径 148.0 mm、スリーブ肉厚 2.0 mm（外径 152.0 mm）。
  - 全体高さ 24.0 mm（スリーブ深さ 21.0 mm、端面板厚 3.0 mm）。
  - 外周上下エッジに 1.0 mm のC面取り、スリーブ開口部内周に 1.0 mm のリードイン案内C面取り。
- **壁立ち上がりの応力集中緩和フィレット (R 2.0 mm)**:
  - スリーブ円筒壁と端面ストッパー座の交差部（根元）に、R 2.0 mm の滑らかな凹フィレット（内隅丸み）を付与。
  - 接地面からのラジアル荷重や曲げモーメントによる根元の応力集中を大幅に低減。
- **端面ボロノイダイヤフラム構造**:
  - コロ転動時に外周が押し潰されて楕円化・座屈するのを防ぐため、端面プレート（厚み 3.0 mm）にボロノイ網を展開。
  - 均一な梁幅 2.2 mm、角部 $R = 0.8\text{ mm}$ のフィレット。
- **3Dプリント性**:
  - 端面側（Z=0）をベッドに向けて配置することで、サポート材不要（100% Support-free）で高精度にFDM造形可能。

## ディメンション仕様

| パラメータ | 寸法 | 説明 |
| :--- | :--- | :--- |
| 円柱嵌合内径 (`fit_id`) | 148.0 mm | 挿入する円柱の外径 |
| スリーブ肉厚 (`sleeve_t`) | 2.0 mm | スリーブ円筒壁の厚み |
| 外径 (`disk_od`) | 152.0 mm | キャップ外径 / コロ転動面径 (`fit_id + 2*sleeve_t`) |
| 全体高さ (`total_h`) | 24.0 mm | 全体の高さ |
| 端面板厚 (`plate_t`) | 3.0 mm | ボロノイ端面プレートの厚み |
| スリーブ深さ (`sleeve_h`) | 21.0 mm | 円柱が挿入される深さ (`total_h - plate_t`) |
| 立ち上がりフィレット (`fillet_r`) | 2.0 mm | スリーブ内壁根元の応力緩和R |
| ストッパー段差幅 (`stop_rim_w`) | 3.5 mm | 円柱端面が突き当たる環状受座の幅 |
| ボロノイ領域径 (`pocket_d`) | 141.0 mm | ボロノイ肉抜き穴が広がる直径 |
| 梁幅 (`strut_w`) | 2.2 mm | ボロノイリブの厚み |
| コーナーフィレット | 0.8 mm | セル角の丸め半径 |
| 外周エッジ面取り (`chamfer_size`) | 1.0 mm | 転動外周エッジのC面取り |
| 挿入リードインC面 (`lead_in_chamfer`) | 1.0 mm | スリーブ開口部内周の案内面取り |

## ファイル構成

- `voronoi_disk.scad`: メインのOpenSCADモデルファイル（完全自律・外部依存なし）
- `voronoi_disk.stl`: 生成済みSTLメッシュファイル

## ビルド方法

OpenSCAD単体でビルド可能です（Python不要）:

```bash
openscad -o voronoi_disk.stl voronoi_disk.scad
```

またはリポジトリルートで:

```bash
make models/voronoi_disk/voronoi_disk.stl
```
